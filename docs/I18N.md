# Ajouter ou corriger une langue

Tout est dans `web/index.html`, dans le bloc `I18N` (première balise `<script>` après
les modules `CORE`/`YCORE`/`TARGETS`).

## Structure

```js
const LANGS = [['fr','Français'], ['en','English'], /* … */];

const I18N = {
  fr: { sub: '…', s1: '…', /* ~80 clés */ },
  en: { … }
};
Object.assign(I18N, { de: {…}, es: {…}, it: {…}, pt: {…}, nl: {…}, pl: {…} });
```

- **clé absente** → repli sur `en`, puis sur la clé brute (visible à l'écran, donc
  facile à repérer) ;
- les valeurs acceptent du HTML (`<span class="mono">`, `<b>`) ;
- les libellés de champs (`fProviderId`, `fCtx`…) reprennent les noms de clés de
  configuration : traduisez-les comme des étiquettes, pas comme du code.

## Procédure

1. ajouter la langue dans `LANGS` **et** dans `I18N` (copier `en`, traduire) ;
2. `npm`-free : aucun build, rechargez `http://127.0.0.1:8766/` ;
3. vérifier dans l'interface :
   - titres des 4 sections, boutons, en-têtes de tableaux, cartes ;
   - bascule de langue puis rechargement (la préférence est en `localStorage`) ;
   - ouvrir *Documentation* : si la langue n'a pas de bloc `DOCS`, la note de repli
     doit apparaître ;
4. vérifier qu'aucun texte français ne subsiste : le plus simple est de chercher
   visuellement « Détection », « Aperçu », « Écrire », « Chemins ».

## Documentation intégrée

`DOCS` ne contient que `fr` et `en` (contenu long : six sections, tableaux, chemins).
Pour ajouter une langue à la documentation, ajouter une entrée `DOCS[code]` avec la
même structure `[ [titre, html], … ]` — sinon l'interface affiche la note
`docsNote` de la langue courante et sert l'anglais.

## Ce qui n'est pas traduit, volontairement

| Zone | Pourquoi |
|---|---|
| Journal (`#log`) | messages de diagnostic et d'erreurs de bibliothèques (`urllib`, `ssl`, `socket`) |
| Panneau de sonde (ids, en-têtes, `HTTP 200`) | sortie brute du serveur |
| Noms de champs de configuration | ce sont les clés que l'on retrouve dans les fichiers écrits |

## Ajouter une chaîne

1. ajouter la clé dans **les huit** dictionnaires (ou au moins `fr` et `en`) ;
2. l'utiliser via `t('maCle')` dans le JS, ou `data-i18n` / sélecteur dans
   `applyI18n` pour le HTML statique ;
3. les textes injectés par JS qui contiennent du HTML utilisent `innerHTML` : ne pas
   y mettre de contenu utilisateur non échappé.
